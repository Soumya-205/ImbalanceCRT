# ImbalanceCRT

## Conformal Risk Training Under Class Imbalance

This project investigates whether the advantages of Conformal Risk Training (CRT) over post-hoc Conformal Risk Control (CRC) remain as class imbalance becomes increasingly severe.

## Models

- Model A: Standard Cross-Entropy + Post-hoc CRC
- Model B: Class-Weighted Fine-Tuning + Post-hoc CRC
- Model C: End-to-End Conformal Risk Training

## Imbalance Levels

- 1%
- 5%
- 10%
- 30%

## Target FNR

- 1%
- 5%
- 10%

## Datasets

- Credit Card Fraud Detection
- Lending Club
